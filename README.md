# MySQL Employee Leave Management System

## 📌 Project Overview

The **Employee Leave Management System** is a database project developed using MySQL to manage employee leave requests and maintain leave-related information in an organization.

This project demonstrates how SQL can be used to store, retrieve, manage, and analyze employee leave data efficiently.

## 🎯 Project Objectives

- Manage employee and leave-related information.
- Store and track employee leave requests.
- Retrieve leave details using SQL queries.
- Analyze leave requests based on status and other criteria.
- Practice database design and SQL operations.
- Improve data management and reporting skills.

## ✨ Key Features

- Employee information management
- Leave request tracking
- Leave status management
- Employee leave data retrieval
- SQL-based data analysis and reporting
- Database relationships and data integrity

## 🛠️ Technologies Used

- **Database:** MySQL
- **Query Language:** SQL
- **Database Tool:** MySQL Workbench
- **Version Control:** Git and GitHub

## 🧠 SQL Concepts Covered

- Database and table creation (`CREATE DATABASE`, `CREATE TABLE`)
- Data manipulation (`INSERT`, `UPDATE`, `DELETE`)
- Data retrieval (`SELECT`, `WHERE`)
- Sorting and filtering (`ORDER BY`, `LIMIT`)
- Aggregate functions (`COUNT()`, `SUM()`, `AVG()`, `MAX()`, `MIN()`)
- Grouping data (`GROUP BY`, `HAVING`)
- Joins (`INNER JOIN`, `LEFT JOIN`)
- Subqueries
- Primary keys and foreign keys
- Constraints and data integrity

## ⚙️ How to Run the Project

1. Install MySQL Server and MySQL Workbench.
2. Clone or download this repository.
3. Open the project’s `.sql` file in MySQL Workbench.
4. Execute the SQL script to create the database and tables.
5. Insert the sample data, if provided.
6. Run the SQL queries to explore and analyze employee leave information.
